# Disrespectacles Privacy Policy

Effective date: October 8, 2026

Disrespectacles adds user-controlled costume overlays to webpages and lets users capture, copy, or save images of those pages.

## Information handled locally

The extension stores costume choices, positions, sizes, rotations, and editing state in Chrome session storage. It associates these settings with a tab identifier and the current website's origin (scheme, hostname, and port) to restore disguises on the same site. It does not build a browsing-history profile or monitor visits for advertising or analytics.

When you choose Capture screenshot, the extension captures the visible area of the active webpage, including any information visible there. Captures are stored locally in Chrome session storage and displayed in an extension preview. Disrespectacles does not scan faces or extract personal information from screenshots.

Copy image writes the selected screenshot to the system clipboard when you request it. The extension does not read clipboard contents. Save PNG downloads the image to your device. If you paste or upload an image elsewhere, that sharing is your action and is subject to the receiving service's practices.

## Use and sharing

Data is used only to provide costume editing, restore disguises, and prepare requested screenshots. The extension does not send these settings, website origins, or screenshots to the developer or external servers. It includes no analytics, advertising, tracking, account login, or remote executable code. The developer does not sell, transfer, or review this data.

Disrespectacles complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. User data is used only for the extension's stated features, not for advertising, creditworthiness, or lending decisions.

## Retention and deletion

Settings are stored for the browser session. Closing a tab removes its saved costume settings. Turning a disguise off may retain its settings so it can be restored. Captures remain in Chrome session storage for the browser session. Restarting the browser, disabling, reloading, or uninstalling the extension clears its session storage. Downloaded files and images copied to the clipboard are outside this session storage and must be deleted or cleared separately using your device's controls.

## Permissions

- activeTab: temporarily access the page you activate the extension on, and capture the visible page when requested.
- scripting: insert the bundled costume overlay and restore it after supported same-site refreshes.
- storage: keep costume settings, website origins, and screenshot previews locally in session storage.
- clipboardWrite: copy a screenshot to the clipboard when you click Copy image.
